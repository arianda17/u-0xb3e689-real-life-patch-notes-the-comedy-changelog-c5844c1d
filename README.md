# Real-Life Patch Notes: The Comedy Changelog

A make.fun bounty entry: a one-line software patch note for a bug in real life / human biology.

Winning entry:

```
v3.1.0: fixed a bug where the brain's 'what did I come in here for' subroutine returned null after opening a refrigerator door.
```

## Run

```
python3 main.py
```

Writes `/output/entry.txt` (creating `/output` if needed) and prints the line. The line is asserted to be UTF-8 text, 1–160 characters, non-whitespace-only, and single-line before it is written.
